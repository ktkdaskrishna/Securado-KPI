│  OPTION 1: MongoDB Atlas (RECOMMENDED) ⭐                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. Create free cluster at: https://www.mongodb.com/cloud/atlas            │
│  2. Create database: platform1_canonical                                    │
│  3. Create users:                                                           │
│     • platform1_writer (readWrite permission)                               │
│     • platform2_reader (read permission)                                    │
│  4. Get connection string:                                                  │
│     mongodb+srv://username:password@cluster.mongodb.net/                    │
│                                                                              │
│  5. Update Platform 2 .env:                                                 │
│     CANONICAL_MONGO_URL="mongodb+srv://platform2_reader:pass@cluster..."   │
│     CANONICAL_DB_NAME="platform1_canonical"                                 │
│                                                                              │
│  6. Platform 1 connects with:                                               │
│     mongodb+srv://platform1_writer:pass@cluster.../platform1_canonical     │
│                                                                              │
│  ✅ Benefits:                                                                │
│     • Free tier (512MB storage)                                             │
│     • Accessible from anywhere                                              │
│     • SSL/TLS enabled                                                       │

📊 DATABASE SCHEMA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Database 1: platform1_canonical (Platform 1 writes, Platform 2 reads)
  Layout Option A: Single Collection
    └── data_lake_canonical (envelope format with entity_type field)
  
  Layout Option B: Per-Entity Collections
    ├── silver_opportunities
    ├── silver_accounts
    ├── silver_contacts
    └── silver_activities

Database 2: platform2_app (Platform 2 operational data)
    ├── users, roles, permissions, departments
    ├── overrides_opportunities, overrides_accounts
    ├── goals, teams, portfolios, initiatives
    ├── activities, kpis, serving_cache
    └── admin_logs_*
