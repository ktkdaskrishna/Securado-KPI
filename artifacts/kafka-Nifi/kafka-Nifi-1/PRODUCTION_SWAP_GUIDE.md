# ESIP Production Swap Guide

## Overview

This guide explains how to swap the dev-mode abstractions in ESIP to production-grade enterprise services.

---

## 1. Kafka Integration (Replace MongoDB Events)

### Current Dev Mode
- Events are stored in MongoDB `events` collection
- Topics simulated via `topic` field

### Production Swap

1. **Install Kafka Python Client**
```bash
pip install confluent-kafka
```

2. **Add Environment Variables**
```env
KAFKA_BOOTSTRAP_SERVERS=broker1:9092,broker2:9092
KAFKA_SASL_USERNAME=your-username
KAFKA_SASL_PASSWORD=your-password
```

3. **Replace Event Publishing in server.py**
```python
from confluent_kafka import Producer

kafka_config = {
    'bootstrap.servers': os.environ.get('KAFKA_BOOTSTRAP_SERVERS'),
    'sasl.username': os.environ.get('KAFKA_SASL_USERNAME'),
    'sasl.password': os.environ.get('KAFKA_SASL_PASSWORD'),
    'sasl.mechanism': 'PLAIN',
    'security.protocol': 'SASL_SSL'
}

producer = Producer(kafka_config)

@api_router.post("/events/publish")
async def publish_event(event: EventCreate):
    producer.produce(
        topic=event.topic,
        key=event.key.encode('utf-8'),
        value=json.dumps(event.payload).encode('utf-8')
    )
    producer.flush()
    return {"status": "published"}
```

## 2. ClickHouse Integration (Replace MongoDB Aggregations)

### Current Dev Mode
- KPI aggregations use MongoDB aggregation pipeline
- Bronze/Silver/Gold layers simulated in collections

### Production Swap

1. **Install ClickHouse Client**
```bash
pip install clickhouse-connect
```

2. **Add Environment Variables**
```env
CLICKHOUSE_HOST=clickhouse.example.com
CLICKHOUSE_PORT=8123
CLICKHOUSE_DATABASE=esip
CLICKHOUSE_USERNAME=default
CLICKHOUSE_PASSWORD=your-password
```

3. **Create ClickHouse Tables**
```sql
CREATE TABLE bronze_opportunity_events (
    tenant_id String,
    event_time DateTime64(3),
    opportunity_id String,
    payload String,
    source_system String,
    event_id UUID
) ENGINE = MergeTree()
ORDER BY (tenant_id, event_time);

CREATE TABLE silver_opportunity (
    tenant_id String,
    opportunity_id String,
    name String,
    amount Decimal64(2),
    stage String,
    is_closed UInt8,
    is_won UInt8,
    owner_user_id String,
    created_at DateTime64(3),
    updated_at DateTime64(3),
    closed_at Nullable(DateTime64(3))
) ENGINE = ReplacingMergeTree(updated_at)
ORDER BY (tenant_id, opportunity_id);
```

4. **Replace kpi_service.py aggregations**
```python
import clickhouse_connect

class KPIService:
    def __init__(self):
        self.client = clickhouse_connect.get_client(
            host=os.environ.get('CLICKHOUSE_HOST'),
            port=int(os.environ.get('CLICKHOUSE_PORT', 8123)),
            database=os.environ.get('CLICKHOUSE_DATABASE'),
            username=os.environ.get('CLICKHOUSE_USERNAME'),
            password=os.environ.get('CLICKHOUSE_PASSWORD')
        )
    
    async def get_pipeline_amount(self, tenant_id):
        result = self.client.query(
            "SELECT sum(amount), count(*) FROM silver_opportunity "
            "WHERE tenant_id = %(tenant_id)s AND is_closed = 0",
            parameters={'tenant_id': tenant_id}
        )
        return {'value': result.result_rows[0][0], 'count': result.result_rows[0][1]}
```

## 3. Cube Semantic Layer (Replace KPIService)

### Current Dev Mode
- `kpi_service.py` computes metrics via MongoDB

### Production Swap

1. **Deploy Cube.js** (via Docker or Cube Cloud)

2. **Create Cube Schema** (`schema/Opportunity.js`)
```javascript
cube('Opportunity', {
  sql: `SELECT * FROM silver_opportunity`,
  
  measures: {
    pipelineAmount: {
      sql: `amount`,
      type: `sum`,
      filters: [{ sql: `${CUBE}.is_closed = 0` }]
    },
    winRate: {
      sql: `CASE WHEN ${closedCount} > 0 THEN ${wonCount} * 100.0 / ${closedCount} ELSE 0 END`,
      type: `number`
    },
    avgDealSize: {
      sql: `amount`,
      type: `avg`,
      filters: [{ sql: `${CUBE}.is_won = 1` }]
    }
  },
  
  dimensions: {
    stage: { sql: `stage`, type: `string` },
    ownerUserId: { sql: `owner_user_id`, type: `string` },
    tenantId: { sql: `tenant_id`, type: `string` }
  }
});
```

3. **Replace API calls in frontend**
```javascript
// From:
kpiAPI.getExecutiveOverview(tenantId)

// To:
const cubejsApi = cubejs(CUBE_TOKEN, { apiUrl: CUBE_API_URL });
const result = await cubejsApi.load({
  measures: ['Opportunity.pipelineAmount', 'Opportunity.winRate'],
  filters: [{ dimension: 'Opportunity.tenantId', operator: 'equals', values: [tenantId] }]
});
```

## 4. WSO2 Identity Server (Replace JWT Auth)

### Current Dev Mode
- Simple JWT tokens generated by FastAPI
- Role-based access in code

### Production Swap

1. **Configure WSO2 Identity Server**
- Create OIDC Application for ESIP
- Configure redirect URIs
- Set up user roles

2. **Add Environment Variables**
```env
WSO2_ISSUER=https://wso2is.example.com/oauth2/token
WSO2_CLIENT_ID=your-client-id
WSO2_CLIENT_SECRET=your-client-secret
WSO2_REDIRECT_URI=https://esip.example.com/callback
```

3. **Replace Frontend Auth**
```javascript
import { useAuth0 } from '@auth0/auth0-react'; // or similar OIDC library

// Configure OIDC provider
const config = {
  domain: process.env.REACT_APP_WSO2_DOMAIN,
  clientId: process.env.REACT_APP_WSO2_CLIENT_ID,
  redirectUri: window.location.origin + '/callback'
};
```

4. **Replace Backend Token Validation**
```python
from jose import jwt
import httpx

async def validate_wso2_token(token: str):
    jwks_url = f"{os.environ.get('WSO2_ISSUER')}/.well-known/jwks.json"
    async with httpx.AsyncClient() as client:
        jwks = await client.get(jwks_url)
        # Validate token against JWKS
        payload = jwt.decode(token, jwks.json(), algorithms=['RS256'])
        return payload
```

## 5. Debezium CDC (Replace Polling)

### Current Dev Mode
- Schema discovery via simulated Odoo API calls
- Changes tracked via timestamp polling

### Production Swap

1. **Deploy Debezium via Kafka Connect**
```json
{
  "name": "odoo-connector",
  "config": {
    "connector.class": "io.debezium.connector.postgresql.PostgresConnector",
    "database.hostname": "odoo-db.example.com",
    "database.port": "5432",
    "database.user": "replication_user",
    "database.password": "password",
    "database.dbname": "odoo",
    "table.include.list": "public.crm_lead,public.crm_stage,public.res_partner",
    "topic.prefix": "odoo"
  }
}
```

2. **Configure Kafka Consumer in Backend**
```python
from confluent_kafka import Consumer

def consume_cdc_events():
    consumer = Consumer({
        'bootstrap.servers': os.environ.get('KAFKA_BOOTSTRAP_SERVERS'),
        'group.id': 'esip-cdc-consumer',
        'auto.offset.reset': 'earliest'
    })
    consumer.subscribe(['odoo.public.crm_lead', 'odoo.public.crm_stage'])
    
    while True:
        msg = consumer.poll(1.0)
        if msg:
            # Process CDC event and load to ClickHouse
            process_cdc_event(msg.value())
```
