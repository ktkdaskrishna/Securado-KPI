**Key Technical Concepts**
- **Redis Integration:** Used as a cache and in-memory data store for the dashboard query engine.
- **Incremental Polling Sync:** A background worker () polls Odoo for changes on a configurable schedule, validates fields, transforms data, and performs UPSERT operations into MongoDB, including handling deletions.
- **Dynamic Query Engine:** A backend service () executes JSON-defined queries (with aggregations, filters, etc.) against MongoDB and returns data formatted for various chart and display types.
- **Configurable React Dashboard:** The frontend fetches a layout template and renders a grid of query cards. A component registry maps each card's display type (e.g., , , ) to a corresponding React component.
- **Centralized User Identity:** A  collection in MongoDB links a user's app email to their canonical Odoo name and ID, making all RBAC and filtering logic resilient to name variations.
